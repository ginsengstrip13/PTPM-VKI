# PTPM-VKI

Репозиторий лабораторных работ по тестированию программных модулей.

## Converter

Класс `Converter` со статическим методом `do(x: float) -> int` реализован
в `converter.py`. Входное число имеет один знак после запятой.
В `tests/test_converter.py` — ровно 10 тестов на `unittest`: положительные
и отрицательные значения, границы диапазонов и исключение `ValueError` при нуле.

```text
python -m unittest discover -s tests -p "test_converter.py" -v
```

## Лабораторная работа 3

Программа: `lab3.py`. Новые тесты: `test_lab3.py`.
В `test_lab3.py` — 5 тестов, из них 3 интеграционных.

```text
python lab3.py
python -m unittest test_lab3 -v
python -m unittest discover -v
```

`main.py` — прежний запуск ЛР1; для третьей работы запускайте `lab3.py`.

## Лабораторная работа 2

В работе проверяются два модуля:

- `validator.py` — валидатор регистрации из лабораторной работы 1;
- `delivery.py` — учебный модуль расчета стоимости доставки.

Тесты написаны на стандартном модуле `unittest`:

- `test_validator.py` — 21 тест, все проходят после исправления валидатора;
- `test_delivery.py` — 19 тестов, все проходят после исправления модуля доставки.

Запуск полного набора:

```text
py -3 -m unittest discover -s . -p "test_*.py" -v
```

В отчете `Отчет_ЛР2_PTPM_VKI.docx` приведены результаты до и после исправления, названия найденных тестами дефектов, строки в `delivery.py` и варианты исправлений.
