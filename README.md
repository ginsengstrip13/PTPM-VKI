# PTPM-VKI

Репозиторий лабораторных работ по тестированию программных модулей.

## Лабораторная работа 2

В работе проверяются два модуля:

- `validator.py` — валидатор регистрации из лабораторной работы 1;
- `delivery.py` — учебный модуль расчета стоимости доставки.

Тесты написаны на стандартном модуле `unittest`:

- `test_validator.py` — 21 тест, все проходят после исправления валидатора;
- `test_delivery.py` — 19 тестов, 15 проходят и 4 фиксируют несоответствия в исходном учебном модуле.

Запуск полного набора:

```text
py -3 -m unittest discover -s . -p "test_*.py" -v
```

В отчете `Отчет_ЛР2_PTPM_VKI.docx` приведены итоговая статистика, названия упавших тестов, строки с дефектами в `delivery.py` и варианты исправлений.
